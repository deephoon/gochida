## 2. 디자인 시스템

### 2-1. 컬러 토큰 (`styles.css` `:root`)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--primary` | `#5B6CFF` | 브랜드 메인 (CTA, 강조) |
| `--primary-light` | `#EEF0FF` | 아이콘 배경, 뱃지 틴트 |
| `--premium-dark` | `#1E2335` | 프리미엄 카드(비용·신뢰·요청서 헤더) |
| `--accent` | `#FFB38A` | 포인트(따뜻한 살구) |
| `--background` | `#F5F5F7` | 화면 캔버스 |
| `--surface` | `#FFFFFF` | 카드 |
| `--success / --warning / --danger` | `#34C759 / #F5A623 / #FF3B30` | 상태 색 |

> 컬러는 Tweaks 패널에서 Primary/Accent를 실시간 교체 가능 (`--primary`, `--accent` CSS 변수 갱신).

### 2-2. 타이포 스케일
`t-display(28~32) · t-h1(24) · t-h2(20) · t-h3(16) · t-body(15) · t-caption(13) · t-small(12)` — 전부 Pretendard, 음수 자간으로 단단한 느낌.

### 2-3. 반경 / 그림자
- 반경: `--r-s(8) ~ --r-3xl(32) ~ --r-pill`
- 그림자: `--shadow-soft / --shadow-medium / --shadow-primary(블루 글로우) / --shadow-float`

### 2-4. 모션 원칙
- **화면 전환**: 짧은 20px 슬라이드(`screenEnter` / `screenEnterBack`) — transform-only & `fill: both`라 애니메이션이 멈춰도 콘텐츠가 화면 밖으로 사라지지 않음(초기 버전의 “빈 화면” 버그 해결).
- **리스트 등장**: `.stagger` 자식 순차 등장(translateY only).
- **터치 피드백**: `.pressable` → `:active`에서 `scale(0.97)`.

## 4. 네비게이션 구조

스펙의 Expo Router `(tabs)` + Stack 혼용 구조를 그대로 HTML 프로토타입으로 옮겼습니다.

### 4-1. 탭 화면 (하단 탭바 노출)
```
home       홈 대시보드
requests   요청 내역
chats      채팅 목록
profile    내 정보
```

### 4-2. 스택 화면 (탭바 숨김 — 프로세스/상세)
```
upload → analysis → review → experts → expertDetail
requestDetail   (요청 상세)
chatDetail      (채팅 상세)
```

### 4-3. 하단 탭바 — 중앙 카메라 FAB ⭐
- 5분할: **홈 · 요청 · [📷 촬영 FAB] · 채팅 · 내 정보**
- 중앙의 떠 있는 그라데이션 **카메라 FAB**가 핵심 서비스(사진으로 바로 시작)를 항상 한 번에 트리거 → `upload`로 진입.
- 채팅 탭에는 미확인 뱃지(1) 표시.
- 프로세스/상세 화면에서는 탭바가 사라짐(`isTab` 판별).

## 5. 화면별 상세

### 5-1. 홈 대시보드 (`screens-core.jsx`)
단순 온보딩 → **생활시공 요청 대시보드**로 재구성.
1. **브랜드 헤더** + 알림 버튼
2. **Hero CTA** — 프라이머리 그라데이션 카드, “사진 한 장이면 충분해요” + 사진으로 시작하기
3. **최근 요청** 카드 (진행 상태 뱃지)
4. **AI 요청서 미리보기** (위치/증상/공종/요청작업 표)
5. **참고 시공 단가** — 가로 스크롤 카드 3종
6. **전문가 응답 예시** — 미니 전문가 카드
7. **작업 확인서·안심 보증** 신뢰 카드 (네이비)

### 5-2. 업로드 (`screens-core.jsx`)
- 드래그-드롭 **사진 슬롯 3개**(`image-slot` 웹컴포넌트, 사용자가 직접 채움)
- **위치 / 증상 칩** 단일 선택
- 3개 항목(사진·위치·증상) 충족 전까지 CTA 비활성 + 남은 개수 안내

### 5-3. AI 분석 (`screens-flow.jsx`)
- 2.4초 **로딩 스켈레톤** + 참고 시세 카드 프리뷰
- 결과: **예상 비용(네이비 카드)** → 문제 후보 → 추천 조치 → AI가 발견한 사항 → 추가 확인 필요(경고) → 직접 확인 가이드/주의
- 위치+증상 조합에 따라 7개 공종 템플릿으로 결과가 달라짐

### 5-4. 요청서 검토 (재디자인 ✨)
- 기존: 밋밋한 표 → **문서형 카드**로 개편
- 네이비 헤더 밴드(“AI 요청서 초안” + 공종 뱃지 + 문서 제목)
- 아이콘이 붙은 필드(문제 위치·의심 원인·요청 작업)
- 글자수 카운터가 있는 **메모 입력** + info 면책 문구

### 5-5. 전문가 응답 비교 (재디자인 ✨)
- “정렬 · 추천순” 칩 + 같은 요청서 기준 안내
- 카드: **그라데이션 링 아바타(최고 평점엔 ‘추천’ 뱃지)** · 작업가능/추가확인 **가능여부 필**
- 코멘트 **말풍선** · 작업방식/비용감각/방문여부 **3-타일 그리드**
- 하단 **보증 스트립**(안심 보증서 · 기간 + 상세 보기)

### 5-6. 전문가 상세 (`screens-flow.jsx`)
신뢰 요소 칩 · 소견 · 상세 표 · **작업 확인서/보증 카드**(포함 항목 체크리스트 + 책임 범위 면책).

### 5-7. 요청/채팅/내 정보 탭 (`screens-tabs.jsx`)
- **요청**: 진행 중/완료 섹션, 상태 뱃지, ‘응답 비교하기’ → experts
- **채팅**: Mock 상담 목록 → **채팅 상세**(말풍선 스레드 + 입력창, 전송은 데모 안내 Alert)
- **내 정보**: 데모 사용자 카드 + 메뉴(사용법/보증서 안내/안전 유의사항/FAQ/앱 정보/데모 안내) — Alert 안내

## 6. 카피 안전성 규칙 (제품 원칙 반영)

AI는 **최종 진단자/확정 견적 산정자가 아님**. 화면 노출 문구에서 아래를 제거/대체했습니다.

| ❌ 금지 | ✅ 사용 |
|---|---|
| 진단 | AI 요청서 정리 / 요청서 초안 |
| 확정 견적 / 최저가 | 참고 시공 단가 / 비용 감각 |
| 무조건·100% 보장 | 작업 확인서 / 안심 보증서 / 사후관리 조건 |
| 플랫폼이 책임집니다 | 전문가 확인 후 달라질 수 있습니다 |

> 예: 홈 3단계 카피의 “AI가 진단” → “AI 요청서 정리”로 교체.

- `STATUS_LABEL` — draft/ai_done/waiting/responded/chatting/completed 상태 라벨

## 8. 변경 이력 (요약)

1. **v1** — 전체 6화면 플로우(홈→업로드→분석→요청서→전문가→상세) 최초 구현, 홈 3변형.
2. **에디토리얼 실험 → 롤백** — 따뜻한 아이보리+세리프 시도 후, 피드백 반영해 **클린 블루**로 복귀하고 **핵심 아이콘(hero.png)**을 홈 중심에 배치.
3. **v4 — 대시보드 + 4탭 네비게이션** — 홈을 대시보드로 재구성, 하단 탭(홈/요청/채팅/내정보) + 요청·채팅·내정보 탭/상세 추가, 카피 안전성 정리, 화면 전환 버그 수정.
4. **v5 — 탭바 카메라 FAB + 핵심 화면 재디자인** — 탭바 중앙 카메라 FAB 추가, 요청서 검토 문서형 재디자인, 전문가 응답 비교 카드 재디자인.
5. **v6 (현재) — 3D 에셋 통합** — 9종 3D 일러스트 에셋을 이름에 맞게 전 화면에 배치(아래 §11).

## 9. 알려진 한계 (데모 범위)

- 실제 사진 분석/AI 호출 없음 — Mock 휴리스틱.
- 채팅 전송·로그인·결제·실시간 통신 미구현(데모 Alert 처리).
- 사진 슬롯은 실제 앱에선 정상 표시되나, 일부 캡처 도구는 웹컴포넌트 내부를 못 잡을 수 있음(실사용엔 영향 없음).
